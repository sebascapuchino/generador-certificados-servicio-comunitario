# Generador de certificados de servicio comunitario

Web autocontenida (un solo archivo `index.html`, sin dependencias) para generar certificados de servicio comunitario de la Escuela de Artes, FHE-UCV.

## Uso
1. Abre `index.html` en el navegador (o activa GitHub Pages: Settings > Pages > Deploy from branch > `main` / root).
2. Escribe nombres, apellidos y cédula, elige el servicio comunitario y la fecha.
3. Pulsa **Generar certificado**, revisa la previsualización y pulsa **Descargar PDF** (elige *Guardar como PDF* y desactiva encabezados y pies de página).
